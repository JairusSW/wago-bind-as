# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Active development |

## Reporting a Vulnerability

Please report vulnerabilities privately to [me@jairus.dev](mailto:me@jairus.dev). Include a minimal reproducer, affected schema or descriptor bytes, expected behavior, actual behavior, and potential impact.

Do not publish the issue before a fix and advisory are available. Memory containment, integer overflow, stale-view use, region data disclosure, and lifecycle races are treated as security-sensitive.
